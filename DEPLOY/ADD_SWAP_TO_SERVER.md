## Управление SWAP в Linux

### Цель
Научиться создавать, включать, изменять и отключать, SWAP-файл в операционной системе Linux.
Эта инструкция поможет вам управлять виртуальной памятью SWAP на Linux, обеспечивая стабильную работу системы при необходимости дополнительной памяти.

### Что же такое SWAP и как работает
SWAP представляет собой виртуальную память на жестком диске, используемую операционной системой в случае нехватки оперативной памяти. 
Когда физическая RAM заполняется, данные могут временно храниться на SWAP, что предотвращает ошибки и падение сервера из-за нехватки памяти.
Да, **SWAP** медленнее, чем обычная **RAM**, и разница может быть **очень значительной**.

### **Почему SWAP медленнее?**
1. **RAM работает на гигабайтах в секунду (GB/s)**, тогда как **диск (HDD/SSD) медленнее на порядки**.
2. **Операции чтения/записи в SWAP происходят через диск**, а диск имеет **высокое время отклика**.
3. **HDD (жёсткий диск) особенно медленный** при случайном доступе к данным.
4. **SSD быстрее HDD**, но всё равно намного медленнее RAM.

---

### **Насколько SWAP медленнее RAM?**
Примерные **средние скорости**:

| Память  | Скорость (MB/s) | Латентность (время отклика) |
|---------|----------------|-----------------------------|
| **DDR4 RAM** (3200 MHz) | ~25,000 MB/s | **наносекунды (ns)** |
| **NVMe SSD (PCIe 4.0)** | ~5,000 MB/s | **миллисекунды (ms)** |
| **SATA SSD** | ~500 MB/s | **миллисекунды (ms)** |
| **HDD (7200 об/мин)** | ~100 MB/s | **миллисекунды (ms)** |

#### **Примерная разница по скорости:**
- **HDD медленнее RAM в ~250 раз**!
- **SATA SSD медленнее RAM в ~50 раз**.
- **NVMe SSD медленнее RAM в ~5 раз**, но всё равно заметно.

---

### **Что это значит на практике?**
- Когда система **начинает активно использовать SWAP**, **замедление очень сильное**.
- На **HDD** это может привести к **лагам, зависаниям, фризам**.
- На **SSD** SWAP работает быстрее, но всё равно **заметно медленнее RAM**.
- Если **SWAP используется постоянно**, лучше **добавить оперативную память**.

📌 **Вывод**: SWAP — это **"запасной вариант"**, но не замена RAM. Он нужен, чтобы система не падала при нехватке памяти, 
но лучше не доводить до состояния при котором система будет использовать только SWAP. 
SWAP полезен на серверах с малым количеством RAM, что бы при билдах или тяжелых нагрузкам на оперативную память
сервер не падал и не зависал.

### Команды что бы создать SWAP
Для создания SWAP-файла размером 1GB выполните следующие команды:
```bash
sudo fallocate -l 1G /swapfile  # Создать файл 1GB в корневом каталоге
sudo chmod 600 /swapfile        # Установить права доступа
sudo mkswap /swapfile           # Создать SWAP-раздел
```

### **1. Почему нужно давать права `600`?**
Команда:
```bash
sudo chmod 600 /swapfile  # Установить права доступа
```
**Зачем?**
- Файл SWAP содержит фрагменты данных, выгруженных из оперативной памяти, которые могут включать в себя пароли, ключи шифрования или другую конфиденциальную информацию.
- Устанавливая права `600`, мы ограничиваем доступ к файлу:
    - **`6` (rw-)** — владелец (root) может читать и записывать файл.
    - **`0` (---)** — остальным запрещён доступ.

Без этого шага SWAP-файл будет доступен другим пользователям, что создаст уязвимость.

### **2. Почему нужно создавать SWAP-раздел?**
Команда:
```bash
sudo mkswap /swapfile  # Создать SWAP-раздел
```
**Зачем?**
- SWAP-файл сам по себе — это просто обычный файл на диске.
- Команда `mkswap` форматирует этот файл в специальный формат SWAP-раздела, чтобы ядро Linux могло его использовать.
- Без `mkswap` система не распознает файл как место для хранения временных данных.

### **Дополнительное пояснение**
Допустим, ты просто создашь файл и попытаешься включить его в SWAP без форматирования:
```bash
sudo fallocate -l 1G /swapfile
sudo swapon /swapfile  # Попытка включить без `mkswap`
```
**Что произойдёт?**  
Система выдаст ошибку, так как файл ещё не подготовлен для работы в режиме SWAP.

Поэтому команда `mkswap` обязательна — она помечает файл как "раздел подкачки", а команда `chmod 600` защищает его от несанкционированного доступа.

### Команды что бы запустить SWAP
Чтобы активировать SWAP-файл, выполните:
```bash
sudo swapon /swapfile  # Включить SWAP
```

Проверить, работает ли **SWAP**, можно несколькими способами.

### **1. Проверка активных SWAP-разделов**
```bash
swapon --show
```
**Что покажет?**  
Если SWAP включён, ты увидишь что-то вроде:
```
NAME       TYPE  SIZE   USED PRIO
/swapfile  file  1G     0K   -2
```
Если список пуст — SWAP не работает.

---

### **2. Проверка через `free`**
```bash
free -h
```
**Вывод будет такой:**
```
              total        used        free      shared  buff/cache   available
Mem:           3.8G        2.1G        300M        150M        1.4G        1.2G
Swap:          1.0G          0B        1.0G
```
Значение в строке **Swap** показывает общий размер SWAP и сколько уже используется.

### **3. Проверка через `top` или `htop`**
- Запусти `top` или `htop` и посмотри строку **Swap** вверху.
- Вывод через top будет такой:
```
Tasks: 147 total,   1 running, 146 sleeping,   0 stopped,   0 zombie

%Cpu(s):  0.8 us,  0.3 sy,  0.0 ni, 98.5 id,  0.0 wa,  0.0 hi,  0.0 si,  0.3 st 

MiB Mem :    914.2 total,     62.0 free,    636.9 used,    381.9 buff/cache     

MiB Swap:   1024.0 total,    674.9 free,    349.1 used.    277.2 avail Mem
```

Если вы увидели что SWAP работает, то все хорошо. На эттом этапе SWAP-файл включен и работает.

---

### Команды что бы остановить SWAP
Для временного отключения SWAP-файла используйте:
```bash
sudo swapoff -a  # Выключить все SWAP-файлы
```

Для окончательного удаления SWAP-файла выполните:
```bash
sudo rm -f /swapfile  # Удалить SWAP-файл
```
---

Если вы хочете изменить размер **SWAP-файла**, то просто так увеличить или уменьшить его не получится — сначала нужно отключить SWAP, изменить размер файла, затем снова включить.

### **Шаги для изменения размера SWAP-файла**

#### **1. Отключить SWAP**
Перед изменением размера сначала отключаем SWAP:
```bash
sudo swapoff /swapfile
```

#### **2. Изменить размер файла**
Например, увеличим до **2GB**:
```bash
sudo fallocate -l 2G /swapfile
```

#### **3. Установить права (на случай, если они сбросились)**
```bash
sudo chmod 600 /swapfile
```

#### **4. Пересоздать SWAP-раздел**
Так как мы изменили размер файла, нужно заново сделать его SWAP-разделом:
```bash
sudo mkswap /swapfile
```

#### **5. Включить SWAP снова**
```bash
sudo swapon /swapfile
```

#### **6. Проверить, что всё работает**
```bash
swapon --show
free -h
```
Теперь размер SWAP должен измениться.
