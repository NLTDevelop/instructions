Чтобы SWAP-файл **автоматически включался после перезапуска инстанса**, нужно добавить его в файл **`/etc/fstab`**.

### **1. Проверить, активен ли SWAP**
Сначала убедись, что SWAP-файл уже работает:
```bash
swapon --show
```
Если он есть в списке, значит, он активен.

---

### **2. Добавить SWAP в `/etc/fstab`**
Открой файл `/etc/fstab` в любом текстовом редакторе:
```bash
sudo nano /etc/fstab
```
Добавь в конец файла эту строку:
```
/swapfile none swap sw 0 0
```
⚡ **Что это значит?**
- `/swapfile` — путь к SWAP-файлу.
- `none` — у SWAP нет точки монтирования.
- `swap` — указывает, что это SWAP-раздел.
- `sw` — стандартные параметры монтирования для SWAP.
- `0 0` — отключает резервное копирование и проверку `fsck` (не нужно для SWAP).

Сохраните файл (`Ctrl + X`, затем `Y` и `Enter`).

---

### **3. Проверить, что всё работает**
Перезагрузи систему если хотите проверить, что SWAP включился:
```bash
sudo reboot
```
После перезагрузки проверь, что SWAP снова включился:
```bash
swapon --show
free -h
```

Теперь SWAP-файл будет автоматически включаться после перезапуска инстанса.

---
Если хочешь **отключить автоматическую загрузку** SWAP после перезапуска, нужно убрать его из `/etc/fstab`.

### **1. Открыть файл `/etc/fstab`**
```bash
sudo nano /etc/fstab
```

### **2. Найти строку**
```
/swapfile none swap sw 0 0
```

### **3. Удалить или закомментировать строку**
Чтобы удалить — просто убери её.  
Или можешь закомментировать (чтобы легко вернуть, если понадобится):
```
# /swapfile none swap sw 0 0
```

### **4. Сохранить и выйти**
Нажми `Ctrl + X`, затем `Y`, потом `Enter`.

---
Теперь SWAP не будет включаться автоматически после того как инстанс перезагрузится.
